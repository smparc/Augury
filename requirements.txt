# Augury — Python dependencies for `apps/augury-signal`.
#
# `apps/augury-signal/pyproject.toml` is the authoritative source; this file
# mirrors its core dependency set for `pip install -r requirements.txt` and for
# tooling that expects a requirements file. If the two disagree, pyproject wins.
#
# Preferred setup — uv provisions the interpreter as well as the environment:
#
#     cd apps/augury-signal
#     uv venv --python 3.12
#     uv pip install -e ".[dev]"
#
# Python 3.12 specifically. 3.13+ runs ahead of torch/dagster wheel
# availability, and 3.11 is the floor for the `datetime.UTC` and `StrEnum`
# usage in the package, so the pin is `>=3.11,<3.13`.
